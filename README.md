## English for IT Project – Bilingual Website

This project aims to develop a bilingual website based on the [WebDesign Final Project](projeto-final/index.html), using language switching with JavaScript `data-i18n` (v1) and using separate folders, `/pt` and `/en` (v2).

Access `v1` [here](https://anabs-escolar.github.io/webdesign-atividades/projeto-final-bilingue-v1/index.html). See the [source code](https://github.com/anabs-escolar/webdesign-atividades/tree/main/projeto-final-bilingue-v1) too.

Access `v2` [here](https://anabs-escolar.github.io/webdesign-atividades/projeto-final-bilingue-v2/en/index.html). See the [source code](https://github.com/anabs-escolar/webdesign-atividades/tree/main/projeto-final-bilingue-v2) too.
